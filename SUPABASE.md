# Supabase

O banco de dados deste sistema está no Supabase da conta **userdashboard@gmail.com**.

Para administrá-lo, acesse o [Dashboard do Supabase](https://supabase.com/dashboard), entre com essa conta e procure pelo projeto do Controle de Distratos.

As URLs e chaves usadas pela aplicação ficam nas variáveis de ambiente `NEXT_PUBLIC_SUPABASE_URL` e `NEXT_PUBLIC_SUPABASE_ANON_KEY`. Não registre chaves neste arquivo.
